## PR #2 review fixes (this session, on top of the published head)

Four findings, all addressed on the existing branch:

1. **FFmpeg `extra_args` escape (media.py)** — the passthrough is now a flag/value-pair allowlist (`SAFE_EXTRA_ARGS`: bitrates, fps, size, sample-rate, channels, durations, preset, crf/qp 0–63, movflags; ≤24 tokens). A second `-i`, `-y`, protocols, maps, filter scripts, or bare paths are rejected with `ValidationError` before any process launches; argv is still executed without a shell.
2. **Cancellation/recovery race (jobs.py)** — cancelling a RUNNING job now enters non-terminal `CANCELLING` (unstarted jobs go straight to terminal `CANCELLED`; double-cancel raises). The task boundary applies terminal `CANCELLED`; `run()` no longer short-circuits so a crash-after-cancel quarantines RUNNING tasks to `NEEDS_RECONCILIATION`; a cancel that lands during the final task (or before the completion check) wins over the success aggregation — never a `SUCCEEDED` overwrite. Schema (`schemas/job.schema.json`), lifecycle doc, and `PROJECT_STATUS.md` describe `CANCELLING`.
3. **Godot evidence overwrite (service.py)** — `_godot_inspect` writes a unique `godot-inspect-<uuid12>.json` per invocation (mirroring the Blender inspector), so `FileAccess.WRITE` truncation can no longer destroy earlier evidence.
4. **This report** — reconciled to the published state (this section).

Regression coverage added to `tests/test_gate2_adapters.py`: non-terminal cancel + double-cancel guard, crash-after-cancel quarantine, cancel-after-completion stays `CANCELLED`, cancel-during-final-task stays `CANCELLED` with the finished task honestly `SUCCEEDED`, `extra_args` escape rejections (11 cases) + safe-tuning acceptance on live ffmpeg, and unique Godot evidence paths across two invocations.
