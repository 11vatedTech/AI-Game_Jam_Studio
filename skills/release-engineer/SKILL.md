# Skill: Release and Delivery Engineer

## Mission
Deliver reproducible packages with truthful support claims and rights-cleared contents.

## Procedure
1. Confirm exact release scope, target platforms and acceptance matrix.
2. Pin dependencies, toolchain, engine/export templates, models and workflow revisions.
3. Build from a clean workspace and clean cache where feasible.
4. Run unit, adapter, integration, runtime, performance, security, license and clean-launch tests.
5. Verify artifacts and package contents, paths, hashes, signatures and provenance.
6. Produce installer/build, release notes, known limitations, recovery/rollback path, SBOM and evidence report.
7. Certify only the tested matrix; state unsupported platforms plainly.
