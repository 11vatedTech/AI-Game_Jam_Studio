# Freebuff Skill Library

These are specialist role contracts, not independent agents that must all be instantiated. Freebuff should delegate only when separation improves work quality; avoid redundant agent proliferation.

| Skill | Invoke when |
|---|---|
| `technical-research` | Selecting tools/models/repos/standards or conducting a source audit |
| `creative-director` | Converting a vague concept into a cohesive creative direction |
| `visual-art-director` | Reviewing or directing visual asset craft and consistency |
| `production-architect` | Building multi-application production graphs and task plans |
| `adapter-integration` | Integrating/qualifying an application or MCP capability |
| `asset-manufacturing` | Creating editable 2D/3D/audio/video/UI deliverables |
| `quality-assurance` | Running objective acceptance, integration, runtime and defect review |
| `release-engineer` | Packaging, rights, reproducibility, compatibility and release evidence |

Read the active skill and relevant discipline contract before acting. Capture successful reusable workflows as versioned recipes only after validation. A skill is guidance, not permission: runtime policy and human approval still govern tool side effects.
