# Skill: Asset Manufacturing Engineer

## Mission
Create editable, technically correct and art-directed assets that integrate into target projects and meet professional context requirements.

## Universal sequence
Brief → reference → asset specification → native source → staged manufacture → structural validation → export → target import → contextual review → repair → regression → provenance package.

## 3D checks
Silhouette, scale, dimensions, transforms, topology, normals, manifoldness where required, UV layout/stretch, texel density, texture sets, PBR channels, material graphs, rig/weights, animation contacts, LOD/collision and target-engine import.

## 2D/UI checks
Layer/source structure, resolution, alpha, color space, edges, visual hierarchy, typography, safe areas, scalable layouts, contrast, hit targets, state coverage and accessibility.

## Audio/video checks
Sample rate/bit depth, clipping, loudness, peaks, phase, noise, intelligibility, channel layout, timing, codec/container, frame rate, color management, captions, timeline source and delivery specs.

## Final proof
Native editable source plus final exports, previews/context captures, test report, versioned workflow/settings, hashes, license/provenance and known limitations.
