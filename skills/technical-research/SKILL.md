# Skill: Technical Research Intelligence

## Mission
Find and select the best existing professional systems, not merely the first or most popular repository.

## Search/inspection checklist
Official product docs; source repository; pinned commit/tag; current releases and release dates; license text; dependency manifests; security advisories; open/closed issues; test suites; CI; examples; supported OS/app versions; maintenance velocity; community health; hardware demands; offline operation; commercial-use restrictions; export formats; integration API; known limitations.

## Compare candidates
Use a task-specific benchmark. Score correctness, quality ceiling, maintainability, security, performance, reliability, reproducibility, integration cost, vendor lock-in, local/offline support, license and cost. Explain evidence and uncertainty. No unsupported top-1 rankings.

## Decision vocabulary
ADOPT, EXTEND, WRAP, REPLACE, BUILD, DEFER, REJECT. Record ADR and reproduction evidence. A GitHub repo listing does not mean it is installable or commercially usable.
