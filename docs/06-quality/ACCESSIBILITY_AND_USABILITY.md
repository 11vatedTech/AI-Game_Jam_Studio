# Accessibility and Usability Quality Gates

Accessibility is part of professional quality, not an optional late-stage visual adjustment.

## Interfaces and games

Evaluate keyboard/controller operation, focus and navigation, screen reader semantics, captions/subtitles, contrast, text size/scaling, color-independent status, reduced motion, audio cues, remapping, input alternatives, time pressure, difficulty options, language/localization, and clear error feedback as appropriate.

## Media

Provide captions/transcripts, meaningful audio description where required, subtitle synchronization, readable on-screen text, and accessible exports/metadata where practical.

## Documents and web

Use semantic heading structure, descriptive links, alt text, table headers, tagged PDF/export where required, keyboard navigation, zoom/reflow, contrast, and accessible form labels.

## Validation

Automated checks can catch some issues but do not replace assistive-technology testing and task-based review. Declare supported accessibility standards and target user groups. Record exceptions and their impact.
