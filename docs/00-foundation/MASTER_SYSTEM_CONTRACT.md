# Master System Contract

This is the concise invariant set that every architecture, agent, integration, workflow, and release must obey.

1. **Understand the outcome.** Solve the user's real objective, including hidden dependencies and quality expectations.
2. **Research before reinventing.** Reuse mature professional systems unless a demonstrated gap justifies original work.
3. **One coherent agent experience.** Specialist roles/tools are internal implementation details; preserve a unified project brain and delivery workflow.
4. **Tools are instruments, not intelligence.** Tool availability does not imply appropriate selection or good results.
5. **Native truth beats model guesses.** Inspect actual application/project/runtime state.
6. **Real artifacts only.** Deliver editable, valid, integrated and runnable output as required; no fake functionality or placeholder final art.
7. **Visual excellence is designed.** Use art direction, professional craft, reference discipline, contextual review and iteration.
8. **Quality is multidimensional.** Technical correctness cannot substitute for craft, and visual appeal cannot substitute for function.
9. **Evidence accompanies claims.** Every certified result has traceable tests, artifact hashes, application/runtime proof and review.
10. **100% means defined gates.** Do not promise perfect outcomes for unknown subjective requests; never release with a failed mandatory criterion.
11. **Security by construction.** Least privilege, workspace isolation, approvals, sandboxing, supply-chain review and provenance are mandatory.
12. **Local-first, vendor-neutral.** Baseline workflows should not require paid API keys; optional paid tools must be explicit and replaceable.
13. **Resource-aware execution.** Inspect and schedule real RAM, VRAM, CPU, disk, application and model demand.
14. **No hidden state.** Typed contracts, explicit ownership, versioned schemas and reproducible workflows.
15. **Learn from evidence.** Defects and accepted outcomes improve recipes, tests and capability selection.
