# Research, Data Analytics, and Knowledge Production

## Scope

Technology research, competitive analysis, literature review, market analysis, structured web research, dataset discovery, data cleaning, exploratory analysis, statistics, visualization, reporting, technical documentation and decision support.

## Workflow

Question framing → research strategy → source discovery → source quality review → extraction → evidence ledger → synthesis → uncertainty/conflict analysis → analysis/code → independent validation → report → reproducibility package.

## Evidence policy

- Prefer primary sources and original data.
- Preserve source URLs, access dates, versions, authors, publication dates and relevant excerpts/claims.
- Separate fact, inference, assumption and recommendation.
- Compare event date with article publication date for news/recent topics.
- Identify conflicting evidence and stale/undated pages.
- Do not fabricate citations, statistics, benchmarks or repository features.
- Record search limitations and unverified claims.

## Analytics acceptance

Validate data schema, missingness, duplicates, units, sampling, selection bias, leakage, assumptions, statistical tests, confidence intervals and visualization integrity. Code and input data versions must reproduce the results. A chart that looks plausible is not proof that the analysis is correct.
