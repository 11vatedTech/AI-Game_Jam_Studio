# Publishing, Packaging, Deployment, and Handoff

## Deliverable types

Game builds, installers, web deployments, mobile packages, desktop apps, media masters, design source packages, CAD/fabrication files, documentation sites, asset packs, datasets, release reports and archives.

## Release requirements

- Clean build/package from source or a documented source project.
- Version, platform, architecture, dependencies, configuration and minimum system requirements.
- File manifest and checksums; license/attribution notices; third-party notices.
- Test report, known limitations, rollback/recovery plan, release notes and owner.
- Verify installation, first launch, upgrade, uninstall, and expected user flows where relevant.
- Verify media metadata, encoding profile, audio sync, color output and platform spec.
- Verify paths, links, fonts, textures, plugins, runtime assets and offline behavior.
- Confirm the artifact opens/runs on a clean machine or isolated environment within the support matrix.

## No silent publish

External release, distribution upload, public announcement, credential use, or paid service activation requires explicit authorization and correct permission scope. A local package is not a published release.
