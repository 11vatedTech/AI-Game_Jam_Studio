# 2D Art, Illustration, Graphics, and Pixel Production

## Capabilities

Concept boards, visual research, illustration, painting, line art, comic pages/panels, character sheets, environments, props, icons, logos, UI assets, diagrams, infographics, sprites, tilesets, pixel art, sprite animation, texture atlases, print layouts, and export preparation.

## Candidate applications

Krita, GIMP, Inkscape, Pixelorama, LibreSprite, Aseprite (commercial), Pencil2D, Tiled, LDtk, Blockbench for compatible low-poly/block styles, and optional proprietary professional products such as Photoshop, Illustrator, Clip Studio Paint, or Affinity products. Verify automation support, file editability, license, and current app version before selection.

## Source/editability requirements

- Preserve layers, groups, masks, vector paths, animation frames, palette, guides, and linked assets when required.
- Store canvas size, resolution, color profile, alpha behavior, bit depth, and export settings.
- For sprite sheets, validate frame size, spacing, trim, pivot, naming, animation metadata, and texture atlas constraints.
- For print, validate bleed, margins, resolution, fonts, embedded links, and output profile.

## Craft review

Composition, visual hierarchy, anatomy/proportion, silhouette, edge control, perspective, value grouping, palette, lighting, readability, texture/detail hierarchy, typography, spacing, consistency, and target-scale legibility. For pixel art additionally check pixel clusters, anti-aliasing style, palette discipline, subpixel artifacts, animation readability, and correct pixel grid.

## Visual moat requirement

AI image generation may assist ideation, reference exploration, texture creation, or paint-over, but it cannot replace structured art direction. Final deliverables need deliberate art decisions, consistent characters/props, clean linework or brushwork, coherent lighting, and editable source where requested.
