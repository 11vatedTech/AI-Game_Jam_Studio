# Capability Universe

This taxonomy is an intended coverage map. It does not imply that every category is implemented or certified. Each capability must be registered individually with inputs, outputs, prerequisites, permissions, tool dependencies, resource estimates, support matrix, tests, and quality criteria.

## 1. Interactive products and game development

- Game concept, genre analysis, GDD, mechanics, economies, progression, balancing, narrative systems, accessibility, platform strategy.
- Unreal Engine, Unity, Godot and future engines; project/scene inspection; code; materials; Blueprints/visual scripting; gameplay systems; physics; AI; UI; save systems; networking; localization.
- Level/world design, lighting, camera, animation, audio, VFX, navigation, controller/input, platform packaging, build pipelines, runtime profiling, automated playtests.
- Interactive fiction, tools, simulations, training applications, XR and installation art.

## 2. 2D visual production

- Research, concept art, illustration, painting, line art, comics, graphic design, icons, sprites, pixel art, tilesets, UI elements, diagrams, infographics, texture sheets, sprite animation, layout, typography, print preparation.
- Layered/editable output where required; palette and style consistency; alpha/bleed/trim and atlas validation.

## 3. 3D and spatial production

- Concept-to-model, sculpting, hard-surface, organic modeling, retopology, UVs, baking, texturing, look development, rigging, animation, simulation, rendering, lighting, compositing, scene assembly.
- CAD, parametric parts, assemblies, constraints, drawings, mechanical/product/industrial design, architecture/BIM, fabrication preparation, 3D printing.

## 4. Materials and rendering

- PBR and stylized materials; procedural node graphs; texture authoring; texture baking; MaterialX/OpenPBR interoperability; shader authoring; color management; render configuration; optimization; LOD and virtual texturing where relevant.

## 5. Motion and performance

- Character and creature rigging; facial systems; retargeting; keyframe animation; mocap cleanup; motion capture editing; camera animation; motion graphics; procedural motion; timing, weight, contacts, loops, and polish.

## 6. VFX and simulation

- Particles, fluids, smoke, fire, cloth, destruction, rigid/soft-body physics, crowds, procedural environments, compositing, tracking, roto, motion design, scientific visualization, cinematic effects.

## 7. Audio and music

- SFX design and editing; foley; music composition; adaptive music; synthesis; orchestration; voice generation/recording/editing; dialogue cleanup; mixing; mastering; loudness/delivery validation; middleware integration.

## 8. Video and cinematography

- Shot planning, storyboards, camera language, lighting plans, scene capture, editing, color grading, compositing, motion graphics, subtitles, versioning, export, and platform delivery.

## 9. UI/UX and applications

- User research, information architecture, interaction design, visual systems, design tokens, components, responsive layouts, prototypes, websites, native applications, dashboards, accessibility, usability testing, frontend/backend implementation, API contracts, deployment.

## 10. Writing, narrative, and brand

- Research, concept development, worldbuilding, screenwriting, branching narrative, dialogue, documentation, marketing, copy, naming, brand strategy, voice/tone systems, editing, localization, publishing.

## 11. Software engineering and technical computing

- Requirements, architecture, code generation/refactoring, debugging, build systems, test engineering, static analysis, performance profiling, security review, database/schema design, APIs, DevOps/CI/CD, simulation, data processing, scientific computing, visualization, automation, robotics/control workflows.

## 12. Publishing and operations

- Asset manifests, versioning, release notes, packaging, installers, platform builds, web deployment, distribution metadata, accessibility/compliance checks, telemetry policy, crash triage, support documentation, archive and handoff.

## Capability maturity levels

- **L0 Listed:** known candidate, no proof.
- **L1 Discovered:** tool and interface located, health not proven.
- **L2 Smoke-tested:** basic operation works in a pinned environment.
- **L3 Workflow-validated:** defined task flow passes complete integration tests.
- **L4 Production-qualified:** quality, failure recovery, security, performance, and provenance gates pass.
- **L5 Certified:** approved support matrix, 100% mandatory suite pass, maintained regression coverage, documented ownership and release process.
