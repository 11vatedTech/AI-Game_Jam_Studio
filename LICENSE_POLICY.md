# License Policy

This specification package does not silently choose a license for the eventual software product. The repository owner must explicitly approve a repository license before public distribution of implementation code.

For every adopted dependency, plugin, model, dataset, font, sound, image, 3D asset, shader, and training artifact, record:

- Exact source URL and immutable revision/version.
- License identifier and link to the full license text.
- Copyright/attribution and notice obligations.
- Commercial use, modification, redistribution, derivative-work, patent, and copyleft requirements.
- Model/dataset-specific restrictions and acceptable-use constraints.
- Whether the item is installed, linked, downloaded, redistributed, or merely referenced.
- Evidence supporting the interpretation and reviewer/date.

Never assume that “open source,” “free,” “public GitHub repository,” “free download,” or “model weights available” means unrestricted commercial use or redistribution. When terms are ambiguous, quarantine the component and obtain appropriate legal review before release. Keep proprietary tools as optional adapters; do not bundle proprietary binaries or assets without rights.
